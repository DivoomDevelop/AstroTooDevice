# 公开发布前的许可证与授权核对

此工程按用户要求建立应用源码与预编译 SDK 的技术边界。该目录尚未上传 Git，也未通过完整许可证审计；没有统一改写原有代码许可证。

1. 核对全志 SDK 合同，确认厂商静态库、接口头文件、Bootloader 二进制、打包程序及资源镜像允许向目标用户再分发。拿到源码或能编译不等于有公开再分发权。
2. `src/middle/minilzo.c` 声明 GPLv2 或更新版本，现有构建使用其解压实现。核实是否已有其他适用授权；否则需处理它对组合 RTOS 程序的 GPL 对应源码义务。预编译 SDK 不会取消这些义务。
3. U-Boot 部分声明 GPL。分发固定 U-Boot 二进制时仍需按适用许可证提供匹配的对应源码与构建材料；SDK 中只有二进制及许可证副本，不能冒充已完成此项。
4. `src/thirdparty/faad2` 即使当前未启用，随应用源码快照分发时也应保留其 GPL、版权和其他声明。核对其他第三方代码，尤其厂商编解码器、工具链及资源的独立条款。
5. 保留许可证和版权信息；对受 GPL 覆盖的部分不添加禁止修改、禁止再分发等额外限制。固定配置是官方构建支持策略。
6. 发布前审核应用源码、资源镜像及调试产物是否含不应公开的业务凭据、内部地址、设备数据或其他第三方材料。SDK 混淆、去符号、固定配置不替代这一审核。

`vendor/` 保存已知许可证原文副本，只是收集起点，不是完整第三方清单或授权证明。
